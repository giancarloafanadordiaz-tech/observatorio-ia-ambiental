# 🌿 Observatorio Iberoamericano de Impacto Ambiental de la IA Generativa

Plataforma web interactiva orientada al monitoreo, estimación y contextualización del consumo energético e hídrico derivado del entrenamiento y despliegue de Modelos de Lenguaje de Gran Escala (GPT-3, GPT-4, Gemini) en Iberoamérica.

## 🚀 Características Principales
- **Contadores Simulados en Tiempo Real:** Métricas de consumo energético (kWh) y gasto hídrico (Litros).
- **Análisis Comparativo de Modelos:** Evaluación visual de parámetros y consumo de GPT-3, GPT-4 y Gemini.
- **Filtro Regional Interactivo:** Contextualización del impacto según el país seleccionado (Colombia, Panamá, Venezuela, México, España, Bolivia).
- **Consola N8N Backend:** Log dinámico de simulaciones de actualización de flujos ETL y Webhooks.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** HTML5, Tailwind CSS (vía CDN), JavaScript (ES6+).
- **Automatización & Data:** Integración conceptual con pipelines de N8N.
- **Hosting:** GitHub Pages.
